# 🍽️ Restaurant Reservation System

A full-stack web application that allows users to book tables and admins to manage reservations efficiently.

## 🚀 Live Demo
https://resturantreservation-ruby.vercel.app/

## 🛠️ Tech Stack
- Frontend: React
- Backend: Node.js / Express
- Database: (MongoDB)
- Deployment: Vercel

## ✨ Features
- User table reservation system
- Admin dashboard to manage bookings
- CRUD operations (Create, Read, Update, Delete)
- Responsive UI for better user experience

## 📂 Installation

### Frontend
cd client
npm install
npm run dev

### Backend
cd server
npm install
npm start
